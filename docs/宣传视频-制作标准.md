**赛事**：2026 首届 JDXplorers 未来青少年 AI 探索者计划 · 赛道一「AI 原点」

## 第 1 节 · 视频定位

### 1.1 一句话定位

**以真实产品录屏为主体的功能演示片**，不是品牌广告片。

视频要在 60 秒内让评委相信三件事：

1. 这个问题是真的、具体的、有人在乎的；
2. AI 在这里面干的是实活；
3. 这个东西**现在就能打开用**。

### 1.2 观众与场景

主观众是赛事评委，可能静音看、可能只看一遍。因此：

- **首 3 秒必须让人看懂这是什么**
- **全程静音也能看懂** → 必须有硬字幕

### 1.3 核心原则：「真实优先」

> **产品功能画面 100% 使用真实录屏。禁止用 AI 生成视频冒充功能演示。**

技术可行性占 20% 权重，考的是"评委能不能当场试用"。视频里的界面如果和评委自己打开 yaoyi.site 看到的不一致，会被判定为"包装出来的作品"。

## 第 2 节 · 风格基调

### 2.1 三个「不」

| 不做 | 原因 |
|---|---|
| **不炫技** | 不用快闪、粒子、故障艺术、赛博感特效 |
| **不悲情** | 不把老人拍成可怜、无助、被抛弃的形象。这是同类作品最容易踩的雷 |
| **不恐吓** | 不出现救护车、ICU、黑白照片、亲人哭泣 |

### 2.2 定调词

> **温暖 · 安静 · 可信**

情绪落点是**"松一口气"**——问题很重，但解决方案很轻。

### 2.3 视觉规范

| 项 | 规范 |
|---|---|
| 主色调 | 沿用产品 UI：**绿色系**（主色 #2E7D32 / #4CAF50）+ 暖白背景 |
| 警示色 | 使用产品自带的橙 #E65100 / 红 #C62828 / #DC2626，保持与界面一致 |
| 光线 | 暖光、自然光。痛点段偏冷，解决方案段转暖 |
| 画面质感 | 干净、留白多、一屏一个信息点 |
| **真人出镜** | **全片零真人出镜**。痛点段用静物空镜（药盒 / 水杯 / 日历 / 窗光） |
| 字体 | 硬字幕用 **思源黑体 / 阿里巴巴普惠体**（开源可商用）。不用系统默认宋体、不用付费字体 |
| 转场 | 仅「淡入淡出」+「覆盖式推入」。禁止翻转、缩放弹跳、随机转场 |
| 画面节奏 | 每个信息点停留 **≥ 2 秒** |

### 2.4 声音规范

| 项 | 规范 |
|---|---|
| 旁白语言 | 普通话 |
| 音色 | 女声温柔 或 男声沉稳，二选一，全片统一 |
| 语速 | **约 4 字/秒**（比正常慢约 20%），呼应产品的 0.8x 慢速播报 |
| **旁白总字数** | **150–180 字**（本片实际约 154 字，有效发声约 39 秒，余下留给画面停顿） |
| 配音方式 | **真人录制**（已确认） |
| 背景音乐 | 温暖钢琴 / 轻弦乐，无鼓点无高潮。音量比旁白低 16–20 dB |
| 音效 | 只在两处：拍照"咔嚓"声、警告"叮—"声 |
| 产品原声 | 防重复 / 冲突场景保留产品内置语音警告原声，增强"真的在运行"的可信度 |

## 第 3 节 · 一分钟时长分配

### 3.1 六段式结构

| 段 | 时间码 | 时长 | 占比 | 内容 | 对应评分维度 |
|---|---|---|---|---|---|
| ① 痛点钩子 | 0:00–0:07 | 7s | 12% | 桌面药盒静物空镜（无真人） | 问题洞察 |
| ② 产品登场 | 0:07–0:12 | 5s | 8% | 打开 yaoyi.site → 首页 | 问题洞察 |
| ③ 核心演示 | 0:12–0:34 | 22s | 37% | 拍照识药 → 四问式结果+语音 → 防重复警告 → 冲突预警 | 智能化效果 / 技术可行性 |
| ④ 家属守护 | 0:34–0:42 | 8s | 13% | 家属端实时事件 → 患者一键求助 → 家属端紧急弹窗 | 技术可行性 |
| ⑤ 价值与 AI 对话 | 0:42–0:53 | 11s | 18% | AI 用药问答 + 无需下载 / 扫码加药 + 价值收束 | 智能化效果 / 商业价值 |
| ⑥ 品牌收尾 | 0:53–0:59 | 6s | 10% | Logo + yaoyi.site + slogan + 免责声明 | 记忆点 |

**成片目标：59 秒**（预留 1 秒缓冲，确保 < 60.0s）

### 3.2 时长红线

1. 任一单段偏离不超过 **+2 秒**，超出部分从第 ⑤ 段压缩
2. **第 ③ 段不得低于 20 秒**
3. **第 ⑥ 段不得少于 5 秒**
4. 导出前用播放器**读秒确认 < 60.0 秒**

## 第 4 节 · 技术交付规范

| 项 | 要求 |
|---|---|
| 容器 / 编码 | MP4（H.264）+ AAC |
| 分辨率 | **1080×1920 竖屏（9:16）** |
| 帧率 | 30 fps |
| 码率 | ≥ 8 Mbps |
| 音频 | 44.1 kHz、192 kbps，响度约 -16 LUFS |
| 字幕 | **全程硬字幕**，简体中文，单行 ≤ 14 字 |
| 文件命名 | `演示视频_药忆_60s.mp4` |
| 文件大小 | ≤ 100 MB |
| 水印 | **不得有任何水印**（详见第 5 节第 6 条） |

## 第 5 节 · 合规与伦理红线

| # | 红线 | 要求 |
|---|---|---|
| 1 | 医疗免责 | 成片必须出现「本产品提供用药参考，不替代医生和药师意见」 |
| 2 | 隐私 | **全片无真人面部**；不出现可识别的患者姓名、病历、真实药单 |
| 3 | 素材版权 | BGM / 字体 / 素材全部使用可商用免费授权 |
| 4 | 不做医疗承诺 | 不用"防止漏服""治愈""替代护士"，改说"提醒""辅助" |
| 5 | 数据真实 | 画面中一切数字必须有实际依据，没有就不出 |
| 6 | **录屏痕迹** | 手机录屏开始/结束时的"正在录制"状态栏与红点，**必须在剪辑中裁掉** |
