> 版本 **v1.4.0** ｜ 已上线 `https://yaoyi.site/` ｜ 单文件 SPA（`index.html` 内嵌全部 CSS/JS，无构建步骤）

## 一、落点：改在哪个页面 / 模块

| 层 | 位置 | 改动 |
|---|---|---|
| **页面** | `#page-history`「📋 用药记录」 | 原来只有"看"，新增删除能力都在这一页 |

## 二、涉及的数据字段与「接口」

### 存储方式（与既有保持一致，未改动）


```js
const STORAGE_KEY = 'yaoyi_medication_records';   // localStorage 单键，整体 JSON 覆盖写
```

### 记录结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | **本次新增**。唯一标识，删除单条记录靠它定位 |
| `drugId` | string | 药品库 key，用于关联 `DRUG_DB` 取名称/用法 |
| `drugName` | string | 药品名（冗余存储，便于记录独立展示） |
| `date` | string | `YYYY-MM-DD`，列表按它分组 |
| `time` | string | `HH:mm` |
| `timestamp` | number | 毫秒时间戳，同一天内按它倒序 |

> **老数据兼容（关键）**：v1.4.0 以前的记录没有 `id`。`loadRecords()` 会按
> `(timestamp|drugId|time)` **派生一个稳定 id 并回写**。派生只依赖记录自身字段，
> 因此**幂等** —— 反复加载结果一致，"删除单条"永远能定位到目标。

### 「接口」= 数据操作函数（沿用现有全局函数风格）

| 函数 | 作用 |
|---|---|
| `recordKey(r)` | 取记录唯一键（`r.id` 优先，兜底派生） |
| `visibleRecords()` | 返回"能渲染出来"的记录（药品已下架的本来就不显示），保证全选与计数与用户所见一致 |
| `deleteRecordsByKeys(keys)` | **核心删除**：按唯一键批量删除，返回实际删除条数 |
| `clearAllRecords()` | 清空全部，返回删除条数 |
| `deleteRecordsByKeys/clearAllRecords` 之后统一调用 `refreshHistoryDependentViews()` | 刷新所有依赖视图 |

## 三、二次确认弹窗（所有删除动作的唯一入口）

- 复用现有 `.alert-overlay` / `.alert-popup` 视觉，边框取危险色，保持全站一致。
- 文案按动作区分：单条写明**药品名 + 日期时间**；批量写明**条数**；
  清空额外写明**「无法恢复」以及会影响哪些统计**。
- ✅ **确认按钮点下去之前，绝不修改任何数据** —— 这是防误删的核心，
  已在回归测试里作为专门断言（"确认之前记录数不变"）。
- 按钮为「确认删除（danger） / 取消」；点遮罩不关闭，必须明确选择。
- `openHistoryConfirm()` 对 DOM 缺失做了兜底：退化为原生 `window.confirm`，功能不会失效。

## 四、删除后同步更新的范围

集中在一个函数里，避免以后新增视图时漏刷：


```js
function refreshHistoryDependentViews() {
  const safe = fn => { try { fn(); } catch (e) { console.warn('刷新失败:', e); } };
  safe(renderHistory);             // 历史列表本身
  safe(renderHistoryInteractions); // 今日药物相互作用提醒
  safe(renderComboAnalysis);       // AI 联合用药分析
  safe(renderAdherenceScore);      // 用药依从性评分
  safe(renderRepurchaseReminder);  // 复购提醒
  safe(renderTodayMeds);           // 首页「今日用药」
}
```

另外的同步细节：

- 记录被删空 → **自动退出批量管理模式**，列表显示空态。
- 无记录时**隐藏工具条**，避免出现"点了没反应"的按钮。
- 离开记录页 → 退出选择模式（`showPage()` 内），下次回来不会停在选择态。

## 五、完整实现代码

### 5.1 数据层：`loadRecords()` —— 补 id（幂等迁移）

```js
function loadRecords() {
  try {
    const data = localStorage.getItem(STORAGE_KEY);
    const records = data ? JSON.parse(data) : [];
    if (!Array.isArray(records)) return [];
    // 兼容早期数据：那时的记录没有 id。这里按字段派生一个**稳定 id** 并回写，
    // 否则"删除单条"无法可靠定位目标。整个过程幂等，重复加载不会有副作用。
    let changed = false;
    for (let i = 0; i < records.length; i++) {
      const r = records[i];
      if (r && !r.id) { r.id = legacyRecordId(r); changed = true; }
    }
    if (changed) saveRecords(records);
    return records;
  } catch (e) {
    return [];
  }
}
```

### 5.2 数据层：`saveRecord()` —— 写入 id

```js
function saveRecord(drug) {
  const records = loadRecords();
  const now = new Date();
  records.push({
    id: newRecordId(),                 // 唯一 id：删除单条记录时靠它定位
    drugId: drug.id,
    drugName: drug.name,
    date: getTodayStr(),
    time: now.getHours().toString().padStart(2, '0') + ':' + now.getMinutes().toString().padStart(2, '0'),
    timestamp: now.getTime()
  });
  saveRecords(records);
}
```

### 5.3 数据层 + 业务层：删除、批量管理、二次确认弹窗

```js
// ============================================================
// 服药历史：删除（单条 / 批量 / 一键清空）
//
// 数据字段：每条记录沿用既有结构，仅**新增一个 id** 用于可靠定位：
//   { id, drugId, drugName, date: 'YYYY-MM-DD', time: 'HH:mm', timestamp }
//   · 老数据没有 id → loadRecords() 会按 (timestamp|drugId|time) 派生一个
//     稳定 id 并回写，因此迁移是幂等的、删除目标永远可定位。
//   · 存储方式不变：仍然是 localStorage 的 yaoyi_medication_records 这一个键，
//     仍然是整体 JSON 覆盖写（见 saveRecords）。
//
// 删除后统一调用 refreshHistoryDependentViews()，把列表与所有依赖记录的
// 统计一起刷新 —— 集中在一处维护，新增视图不会漏刷。
// ============================================================

// 老记录（无 id）的派生 id：由字段本身决定，多次加载结果一致
function legacyRecordId(r) {
  return 'legacy_' + (r && r.timestamp ? r.timestamp : 0)
    + '_' + (r && r.drugId ? r.drugId : '')
    + '_' + (r && r.time ? r.time : '');
}

function newRecordId() {
  return 'r' + Date.now().toString(36) + Math.random().toString(36).slice(2, 8);
}

// 记录的唯一键（迁移之后 id 一定存在，这里再兜一层）
function recordKey(r) {
  if (!r) return '';
  return r.id || legacyRecordId(r);
}

// 只统计"能渲染出来"的记录（药品已从内置库里移除的记录本来就不显示），
// 保证「全选」和计数与用户看到的条目一致
function visibleRecords() {
  return loadRecords().filter(r => r && DRUG_DB[r.drugId]);
}

// 按唯一键批量删除，返回实际删除条数
function deleteRecordsByKeys(keys) {
  const set = new Set((keys || []).filter(Boolean));
  if (!set.size) return 0;
  const records = loadRecords();
  const kept = records.filter(r => !set.has(recordKey(r)));
  const removed = records.length - kept.length;
  if (removed > 0) saveRecords(kept);
  return removed;
}

function clearAllRecords() {
  const n = loadRecords().length;
  if (n > 0) saveRecords([]);
  return n;
}

// 删除后刷新所有依赖用药记录的视图（漏一个就会出现"列表变了、统计没变"）
function refreshHistoryDependentViews() {
  const safe = fn => { try { fn(); } catch (e) { console.warn('刷新失败:', e); } };
  safe(renderHistory);            // 历史列表本身
  safe(renderHistoryInteractions);// 今日药物相互作用提醒
  safe(renderComboAnalysis);      // AI 联合用药分析
  safe(renderAdherenceScore);     // 用药依从性评分
  safe(renderRepurchaseReminder); // 复购提醒
  safe(renderTodayMeds);          // 首页「今日用药」
}

// ---- 二次确认弹窗 ----
// 所有删除动作都必须先经过它。DOM 缺失时退化为原生 confirm，功能不会失效。
let historyConfirmState = null;

function openHistoryConfirm(opts) {
  opts = opts || {};
  const overlay = document.getElementById('history-confirm-overlay');
  if (!overlay) {
    const text = (opts.title || '确认删除？') + '\n' + String(opts.desc || '').replace(/<[^>]+>/g, '');
    if (window.confirm(text)) { try { opts.onConfirm && opts.onConfirm(); } catch (e) { console.error(e); } }
    return;
  }
  historyConfirmState = opts;
  const icon = document.getElementById('hc-icon');
  const title = document.getElementById('hc-title');
  const desc = document.getElementById('hc-desc');
  const ok = document.getElementById('hc-ok');
  if (icon) icon.textContent = opts.icon || '🗑️';
  if (title) title.textContent = opts.title || '确认删除？';
  if (desc) desc.innerHTML = opts.desc || '';
  if (ok) ok.textContent = opts.okText || '确认删除';
  overlay.classList.add('show');
  overlay.style.display = 'flex';
}

function closeHistoryConfirm() {
  const overlay = document.getElementById('history-confirm-overlay');
  if (overlay) { overlay.classList.remove('show'); overlay.style.display = 'none'; }
  historyConfirmState = null;
}

function confirmHistoryAction() {
  const st = historyConfirmState;
  closeHistoryConfirm();
  if (st && typeof st.onConfirm === 'function') {
    try { st.onConfirm(); }
    catch (e) { console.error('删除失败:', e); showToast('删除失败，请重试', 'warning'); }
  }
}

// ---- 三种删除入口 ----
function requestDeleteRecord(key) {
  const target = loadRecords().find(r => recordKey(r) === key);
  if (!target) {
    showToast('这条记录已经不在了', 'warning');
    refreshHistoryDependentViews();
    return;
  }
  openHistoryConfirm({
    icon: '🗑️',
    title: '删除这条用药记录？',
    desc: '<b>' + aiEscapeText(target.drugName) + '</b> · ' + aiEscapeText(target.date + ' ' + target.time)
        + '<br>删除后无法恢复，相关统计会同步更新。',
    okText: '确认删除',
    onConfirm: function () {
      const n = deleteRecordsByKeys([key]);
      showToast(n ? '已删除 1 条记录' : '这条记录已经不在了', n ? 'success' : 'warning');
      refreshHistoryDependentViews();
    }
  });
}

function requestDeleteSelected() {
  const keys = Array.from(historySelectedKeys);
  if (!keys.length) { showToast('请先勾选要删除的记录', 'warning'); return; }
  openHistoryConfirm({
    icon: '🗑️',
    title: '删除选中的 ' + keys.length + ' 条记录？',
    desc: '删除后无法恢复，相关统计会同步更新。',
    okText: '确认删除 ' + keys.length + ' 条',
    onConfirm: function () {
      const n = deleteRecordsByKeys(keys);
      exitHistorySelectMode();
      showToast('已删除 ' + n + ' 条记录', n ? 'success' : 'warning');
      refreshHistoryDependentViews();
    }
  });
}

function requestClearAllRecords() {
  const total = loadRecords().length;
  if (!total) { showToast('还没有用药记录', 'warning'); return; }
  openHistoryConfirm({
    icon: '⚠️',
    title: '清空全部用药记录？',
    desc: '将删除全部 <b>' + total + ' 条</b>记录，<b>无法恢复</b>。<br>'
        + '用药依从性评分、联合用药分析等统计会一并归零。',
    okText: '确认清空',
    onConfirm: function () {
      const n = clearAllRecords();
      exitHistorySelectMode();
      showToast('已清空 ' + n + ' 条记录', 'success');
      refreshHistoryDependentViews();
    }
  });
}

// ---- 批量管理（选择模式）----
// 状态变量 historySelectMode / historySelectedKeys 声明在文件顶部的「核心状态」区

function toggleHistorySelectMode() {
  historySelectMode = !historySelectMode;
  historySelectedKeys.clear();
  renderHistory();
}

function exitHistorySelectMode() {
  historySelectMode = false;
  historySelectedKeys.clear();
  renderHistory();
}

function toggleRecordSelected(key) {
  if (!key) return;
  if (historySelectedKeys.has(key)) historySelectedKeys.delete(key);
  else historySelectedKeys.add(key);
  renderHistory();
}

function toggleSelectAllRecords() {
  const all = visibleRecords().map(recordKey);
  if (all.length && historySelectedKeys.size >= all.length) historySelectedKeys.clear();
  else all.forEach(k => historySelectedKeys.add(k));
  renderHistory();
}


function saveRecord(drug) {
  const records = loadRecords();
  const now = new Date();
  records.push({
    id: newRecordId(),                 // 唯一 id：删除单条记录时靠它定位
    drugId: drug.id,
    drugName: drug.name,
    date: getTodayStr(),
    time: now.getHours().toString().padStart(2, '0') + ':' + now.getMinutes().toString().padStart(2, '0'),
    timestamp: now.getTime()
  });
  saveRecords(records);
}
```

### 5.4 视图层：`renderHistory()`

```js
function renderHistory() {
  const container = document.getElementById('history-list');
  const toolbar = document.getElementById('history-toolbar');
  const selbar = document.getElementById('history-selbar');
  const records = visibleRecords();   // 只渲染药品仍在库里的记录（与既有行为一致）

  // 工具条：没有记录时不显示，避免点了没反应
  if (toolbar) {
    toolbar.style.display = records.length ? 'flex' : 'none';
    const manageBtn = document.getElementById('history-manage-btn');
    if (manageBtn) manageBtn.textContent = historySelectMode ? '完成' : '批量管理';
  }
  // 记录被删空时自动退出选择模式
  if (!records.length) { historySelectMode = false; historySelectedKeys.clear(); }
  if (selbar) selbar.classList.toggle('show', historySelectMode && records.length > 0);
  if (historySelectMode && records.length) {
    const cnt = document.getElementById('hs-count');
    if (cnt) cnt.textContent = '已选 ' + historySelectedKeys.size + ' / ' + records.length + ' 条';
    const allBtn = document.getElementById('hs-all');
    if (allBtn) allBtn.textContent = (historySelectedKeys.size >= records.length) ? '取消全选' : '全选';
  }

  if (records.length === 0) {
    container.innerHTML = '<div class="empty-state"><span class="empty-icon">📋</span>还没有用药记录<br>拍一下药盒开始记录吧</div>';
    return;
  }

  // 按日期分组
  const grouped = {};
  records.forEach(r => {
    if (!grouped[r.date]) grouped[r.date] = [];
    grouped[r.date].push(r);
  });

  // 按日期倒序
  const dates = Object.keys(grouped).sort().reverse();

  let html = '';
  dates.forEach(date => {
    const isToday = date === getTodayStr();
    const dateLabel = isToday ? '今天（' + date + '）' : date;
    html += '<div class="history-date-group"><div class="history-date">' + dateLabel + '</div>';
    // 当天记录按时间倒序
    const dayRecords = grouped[date].sort((a, b) => b.timestamp - a.timestamp);
    dayRecords.forEach(r => {
      const drug = DRUG_DB[r.drugId];
      if (!drug) return;
      const key = recordKey(r);
      const selected = historySelectedKeys.has(key);
      const keyAttr = aiEscapeText(key);

      if (historySelectMode) {
        // 选择模式：整行可点，左侧圆形勾选框
        html += `
        <div class="history-item${selected ? ' selected' : ''}" data-key="${keyAttr}" onclick="toggleRecordSelected(this.getAttribute('data-key'))">
          <div class="h-check">✓</div>
          <div class="h-info">
            <div class="h-name">${drug.name}</div>
            <div class="h-detail">${drug.plain_class} · ${drug.frequency}</div>
          </div>
          <div class="h-time">${r.time}</div>
        </div>`;
      } else {
        html += `
        <div class="history-item" data-key="${keyAttr}">
          <div class="h-icon">💊</div>
          <div class="h-info">
            <div class="h-name">${drug.name}</div>
            <div class="h-detail">${drug.plain_class} · ${drug.frequency}</div>
          </div>
          <div class="h-actions">
            <div class="h-time">${r.time}</div>
            <button class="h-del" type="button" title="删除这条记录" aria-label="删除这条用药记录"
              onclick="event.stopPropagation();requestDeleteRecord(this.closest('.history-item').getAttribute('data-key'))">🗑</button>
          </div>
        </div>`;
      }
    });
    html += '</div>';
  });
  container.innerHTML = html;
}
```

## 六、使用说明

### 删除单条

1. 首页点「📋 用药记录」进入记录页。
2. 找到目标记录，点右侧的 **🗑** 按钮。
3. 弹窗会显示**要删的是哪个药、哪天的哪一时刻**；确认无误后点「确认删除」。
   点「取消」不会有任何改动。

### 批量删除

1. 记录页顶部点「**批量管理**」→ 每行左侧出现圆形勾选框，点整行即可勾选。
2. 用「**全选 / 取消全选**」快速选中，或逐条点选；计数条实时显示「已选 N / M 条」。
3. 点「**删除选中**」→ 二次确认 → 完成。删除后自动退出管理模式。
4. 中途想退出，点「取消」或顶部的「完成」，都不会改动数据。

### 一键清空

1. 记录页顶部点「**🗑 清空全部**」。
2. 弹窗写明**将删除多少条**、**无法恢复**、以及会影响哪些统计。
3. 点「确认清空」即清空。

### 影响范围（删除后会一起变化的地方）

| 位置 | 变化 |
|---|---|
| 用药记录列表 | 立即少掉被删的条目 |
| 首页「今日用药」 | 当天的记录同步减少 |
| 用药依从性评分 | 按剩余记录重新计算 |
| AI 联合用药分析 | 按剩余记录重新分析 |
| 复购提醒 | 按剩余记录重新评估 |
| 重复服药提醒 | 直接读记录，下次进入结果页即以新数据为准 |

### 数据安全边界

- 记录只存在**这台设备的浏览器**里（`localStorage`）；清除浏览器数据、换设备都看不到，
  删除后**没有云端副本可恢复**。
- 正因为无法恢复，所有删除动作才强制走二次确认，且文案里明确写"无法恢复"。
