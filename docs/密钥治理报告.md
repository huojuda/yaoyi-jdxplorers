## 第五步 · 上线（已执行）

### 通道终于通了

前面卡住的两个原因：GitHub 连接器只有只读权限（403 `Resource not accessible by integration`），
而 `github.com` 被 DNS 劫持（`git push` 报 `CONNECT tunnel failed, response 502`）。

关键发现：**`api.github.com` 是通的**（HTTP 200 / 0.52s）。所以不需要 `github.com` ——
走 REST Git Data API 的 blob → tree → commit → PATCH ref 四步，等价于一次真 push。

为此新写了一个通用单文件推送器 `.workbuddy/push_file_via_gitdata.py`
（原有 `deploy_via_gitdata.py` 只同步 `index.html` + `tts/*.mp3`，且提交信息写死为 v1.4.3，
推不了 `.gitignore`）。
