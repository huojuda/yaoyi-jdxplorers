## 一、作品定位

面向阿尔茨海默症（AD）患者的 **AI 拍照用药助手**，移动端单页 H5（PWA）。
核心命题：现有用药 App 都默认用户「看得懂说明书、记得住吃没吃、会操作 App」——而这恰恰是 AD 患者最先丧失的能力。

## 二、功能全景（共 10 个模块）

### 模块 1 · 账号与会话

| 功能 | 说明 |
|---|---|
| 注册 / 登录 | 手机号 + 密码，**双角色**：患者·长辈 / 家人·监护人，注册时填称呼 |
| 会话管理 | 令牌 7 天有效；登录失败 5 次锁定 10 分钟 |
| 密码重置 | 无短信验证码，凭手机号 + 新密码重置；60 秒冷却 + 5 次失败锁定 |
| 注销账号 | 支持删除账号 |
| **一键体验（演示账号）** | 无需注册直接登录，并自动填充 7 天用药数据（6 种药 + 饮酒标记），用于快速演示 |
| 数据命名空间隔离 | 本地数据键为 `base::u_<userId>`，未登录为 `base::guest`；登出彻底清除 |

代码位置：`#page-auth`、`handleAuthSubmit()`、`demoLogin()`、`fillDemoDataIfNeeded()`、`edge-functions/api/auth.js`

### 模块 2 · 首页

| 功能 | 说明 |
|---|---|
| 智能问候 | 按当前时段生成问候语 + 当日日期 |
| 今日用药概览 | 汇总今天已服的药，动态渲染 |
| 三大入口 | ① 扫码加药 ② 拍药盒识药 ③ 用药记录 / 家属查看 |
| **快速体验区** | 3 张预置药卡（多奈哌齐 / 阿司匹林 / 二甲双胍），点击直接跳结果页，跳过拍照 |
| AI 智能提醒卡 | 按当前时段显示「建议服药时间表」⚠️ *演示数据* |

代码位置：`#page-home`、`initHome()`、`renderTodayMeds()`、`quickExperience()`、`showAIReminder()`

### 模块 3 · 取药信息（三条并行入口）

**入口 A · 拍照识药**
- 调用摄像头取景（HTTPS 下），Canvas 取帧 → `capturePhoto()`
- 状态机 `cameraState`：idle / starting / ready / unavailable，状态文案实时提示
- 摄像头不可用时同页降级，不跳页

**入口 B · 相册选图**
- `#file-input` → `handleFileSelect()`，与拍照共用同一条识别链

**入口 C · 扫码加药**（京东生态结合）
- 扫描京东大药房药盒二维码 → 显示订单号 + 药品信息 → 「添加到我的用药」
- ⚠️ *演示：`simulateScan()` 为模拟扫码*

**共用前置处理**
- `compressImageDataUrl()`：缩到 maxSide 1280 → 质量 0.8 起降 → 每轮尺寸 ×0.75，直到 base64 < 700KB
- 超长图另有 `recognizeViaChunks()` 分片兜底通道

### 模块 4 · AI 识别（/api/recognize）

| 功能 | 说明 |
|---|---|
| 多模态识药 | 火山方舟 `doubao-seed-2-0-mini-260428`，返回药品通用名 / 商品名 / 规格 / 频次 / 时间 / 餐次 / 禁忌 / 置信度 |
| 识别动画 | 四步进度（图像预处理 → OCR 文字识别 → 匹配药品数据库 → 生成用药指导），每步 650ms；**最后一步打勾等接口就绪才落笔** |
| 药品库匹配 | 识别出的药名 → 匹配本地 **50 种**药品知识库，补全药盒上没印的信息 |
| 双通道 | POST 直传 + GET 分片通道（应对 EdgeOne 预览环境丢弃大 body） |

### 模块 5 · 结果页（四问式 + 语音）

| 功能 | 说明 |
|---|---|
| 四问式卡片 | 一天吃几次 / 什么时间吃 / 饭前还是饭后 / 有什么禁忌，大字卡片 |
| 药品信息头 | 药品名、药物分类、识别置信度 |
| 语音播报 | 三种状态：🔊 语音播报 / ⏸️ 暂停播报 / ▶️ 继续播报；暂停优先用引擎原生 pause/resume |
| **预渲染音频优先** | 命中 `tts/tts_<drugId>.mp3`（48 个）直接播音频，一次 `speechSynthesis` 都不调用 |
| **方言切换** | 普通话 / 粤语 / 四川话；粤语按音色匹配（HK/yue），四川话在无音色时用慢速+低音调模拟 |
| 重复服药警告 | 命中历史记录 → 红色警示 + 隐藏确认按钮 + AI 生成提醒话术 + 「再听一遍提醒」 |
| 异常行为检测 | ① 凌晨 0–5 点服药提醒 ② 一天内识别同一药 ≥2 次提醒 |
| 确认已服用 | 写入用药记录 + 上报事件到家属端 |

## 五、技术实现要点

- **单文件 SPA**：`index.html` 内嵌全部 CSS/JS，无构建步骤
- **PWA**：`manifest.json` + `sw.js`（API 纯网络 / 导航网络优先 / 静态资源缓存优先）
- **边缘函数**：EdgeOne Pages，6 个文件（实际在用 5 个，`pair.js` 已被 `relation.js` 取代）
- **本地存储**：命名空间 `scopedKey()`，键清单 `USER_DATA_BASE_KEYS` / `USER_DATA_PREFIXES`
- **模型**：火山方舟 `doubao-seed-2-0-mini-260428`，API Key 仅存边缘环境变量
- **数据库**：Upstash Redis（`session:*` / `user:*` / `relation:*` / `bindCode:*`）
