根目录直接映射站点根目录。

**铁证（时间戳吻合）**：
- 更正前 `origin/main` HEAD = `374ae0c`（v1.3.0，2026-09-11 15:12:29 GMT）

**EdgeOne 规则备忘**：目录必须是 `edge-functions/`（不是 `functions/`）；
按文件路径自动生成路由；handler 必须是 `export default function onRequest(context)`；
运行在 V8 隔离环境（非 Node），可用 Web API，不支持 npm 依赖；
**路由大小写敏感**；**静态资源优先于函数路由**。
