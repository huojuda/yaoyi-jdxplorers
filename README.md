# 药忆 — AI 拍照用药助手（H5 原型）

> JDXplorers 参赛作品 · 赛道一「AI原点」
> 面向阿尔茨海默症患者的 AI 拍照用药助手

---

## 快速开始

**直接双击 `index.html`**，用 Chrome / Edge 浏览器打开即可运行。

- 电脑端：可体验完整交互流程（拍照功能需摄像头，建议用手机体验）
- 手机端：用手机浏览器打开，可调用真实摄像头拍照
- 无需安装任何依赖，无需服务器

## 已实现功能

### 1. 首页
- 智能问候语（根据时间显示早上好/下午好/晚上好）
- 今日日期显示
- 超大拍照按钮（占屏幕核心位置）
- 今日用药记录概览

### 2. 拍照识药
- 调用手机后置摄像头（`getUserMedia`）
- 实时取景框 + 对准引导
- 拍照按钮（圆形大按钮）
- **降级方案**：摄像头不可用时自动切换为"从相册选择照片"

### 3. AI 识别流程（动画）
- 扫描线动画
- 四步识别进度：图像预处理 → OCR文字识别 → 匹配药品数据库 → 生成用药指导
- 每步有状态变化（等待中 → 处理中 → 完成✓）

> **当前为演示模式**：识别结果根据图片哈希值从内置药品库中匹配。后续可替换为真实多模态大模型 API。

### 4. 四问式结果页
- 药品名称 + 通俗分类 + 商品名 + 置信度
- **一天吃几次？**（大字体答案 + 详细剂量）
- **什么时间吃？**
- **饭前还是饭后？**
- **有什么禁忌？**（橙色警告卡片）

### 5. 语音播报
- 一键语音播报完整用药指导
- 0.8 倍慢速（适老化）
- 中文语音自动选择
- 播报中可随时停止
- 播报时按钮变红 + 脉冲动画

### 6. 防重复服药（核心差异化功能）
- 每次确认服药后记录到本地存储
- 再次识别同一种药时，自动检测今天是否已服用
- 如已服用，显示红色震动警告："您今天 X 点已经吃过这个药了"
- 重复时隐藏"确认已服用"按钮，防止误操作

### 7. 用药记录
- 按日期分组展示历史用药记录
- 显示药品名、通俗分类、服用时间
- 今日记录高亮

## 如何接入真实 AI 识别 API

当前识别为演示模式（根据图片哈希匹配药品）。要接入真实多模态大模型，需要：

### 你需要提供的：

1. **API 密钥**：豆包视觉理解 / GPT-4V / 其他多模态大模型的 API Key
2. **API 端点**：对应的 API 调用地址
3. **调用方式**：是直接前端调用还是需要后端代理（出于安全考虑，API Key 不应暴露在前端）

### 替换位置：

在 `index.html` 中找到 `finishRecognition()` 函数，将其中的演示逻辑：

```javascript
// 当前演示逻辑
const hash = simpleHash(currentImageData || '');
const drugKey = drugKeys[hash % drugKeys.length];
currentDrug = DRUG_DB[drugKey];
```

替换为真实 API 调用：

```javascript
// 真实API调用示例
async function finishRecognition() {
  const result = await callVisionAPI(currentImageData);
  // result 包含识别到的药品名称
  const drugKey = matchDrugInDatabase(result.drugName);
  currentDrug = DRUG_DB[drugKey];
  renderResult(currentDrug);
}
```

## 浏览器兼容性

| 浏览器 | 拍照 | 语音播报 | 备注 |
|---|---|---|---|
| Chrome（安卓） | ✅ | ✅ | 推荐 |
| Edge | ✅ | ✅ | 推荐 |
| Safari（iOS） | ✅ | ✅ | 需HTTPS或localhost |
| 微信内置浏览器 | ⚠️ | ✅ | 摄像头可能受限 |
| Firefox | ✅ | ⚠️ | 语音支持有限 |

> **注意**：`getUserMedia` 需要 HTTPS 环境或 localhost。直接用 `file://` 协议打开时，部分浏览器可能不允许调用摄像头，此时会自动降级为"从相册选择照片"。部署到 HTTPS 服务器后可正常使用摄像头。
