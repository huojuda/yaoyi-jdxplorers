## 一、项目简介

药忆是一款专为轻中度阿尔茨海默症（AD，俗称 "老年痴呆"）患者设计的 AI 拍照用药助手。患者只需用手机对准药盒拍一张照片，系统通过多模态大模型自动识别药品，并以**大字体 + 慢速语音**回答四个最关键的问题：一天吃几次、什么时间吃、饭前还是饭后、有什么禁忌。同时具备防重复服药确认、规则 + AI 双通道药物相互作用分析、AI 用药问答和家属远程守护能力。

**核心差异化**：AD 患者用药的核心障碍不是 "看不清"，而是 "记不住"—— 记不起有没有吃过药、分不清几种药、看不懂说明书。普通用药提醒 App 本质是 "闹钟 + 服药日志"，而药忆是 "**懂 AD 患者的 AI 照护搭档**"：拍照即懂药、重复即拦截、风险即预警、家属即知情、离线也能用。

## 二、用户与核心场景

### 双用户模型



| 角色      | 人群        | 核心诉求                  | 关键设计                                       |
| ------- | --------- | --------------------- | ------------------------------------------ |
| **患者端** | 轻中度 AD 老人 | 独立、安全地把药吃对            | 极简拍照、大字大按钮、0.8 倍慢速语音、两步内出结果、防重复红色拦截        |
| **家属端** | 子女 / 护工   | 不在身边也能确认老人吃对药、出事能及时知道 | 8 位绑定码关联、3 秒轮询服药 / 求助事件、30 分钟监视期、用药日报、一键拨号 |

约 80% 的 AD 患者由家属居家照护，家属既是高频使用者，也是付费与传播的关键人。

### 核心场景（聚焦 "多药联用、独居、记不住"）



1. **拍照问药**：老人面对几种药，拍一张照片就听到 "这是什么药、怎么吃、要注意什么"。

2. **防重复服药**：老人忘记已经吃过、又拿起同一种药，本地规则即时红色震动警告并语音拦截，AI 再补一句个性化温和提醒。

3. **多药联用风险**：老人同时服用降压、降糖、抗凝等多种药物，内置 40 条规则即时速查，大模型再做一次深度联合用药分析。

4. **家属远程守护**：患者确认服药、按下求助，家属端实时收到通知与弹窗；用药日报汇总漏服、冲突与依从性。

5. **弱网 / 离线**：Service Worker 缓存应用外壳，断网时仍能打开应用、查看本地用药记录。

## 三、市场背景与数据支撑



* **患者规模庞大**：《中国阿尔茨海默病报告 2024》（仁济医院牵头，2024-07）显示，我国 AD 及其他痴呆患者约 **1699 万例**，约占全球 30%；60 岁以上发病率超 5%，85 岁以上约 30%，已居城乡死因第五位。[来源](https://sh.chinadaily.com.cn/a/202407/17/WS66972450a3107cd55d26b78c.html)

* **用药错误高发**：《阿尔茨海默病患者安全调查报告》（中国老年保健协会等，2025-09）显示，近一年 AD 患者用药错误发生率超过半数，其中漏服 49.6%、拒服 24.7%、错服 18.7%、藏药 14.3%，73.6% 的家庭曾遇到用药安全风险。[来源](http://m.toutiao.com/group/7552160102606848550/)

* **居家照护为主、家属负担重**：系统综述显示约 80% 的患者居家照护（[Frontiers in Psychiatry, 2022](https://www.frontiersin.org/journals/psychiatry/articles/10.3389/fpsyt.2022.1004552/full)）；《2019 中国阿尔茨海默病患者家庭生存状况调研报告》显示 65.43% 的照护者心理压力大、68.69% 健康受影响、78.39% 社交受影响。[来源](https://news.cctv.com/2020/01/10/ARTIxhJq8hdgMqNrFPI1zmhx200110.shtml)

### 商业模式（B2B2C 为主）



* **B 端机构订阅（主）**：向养老院 / 护理院、社区卫生服务中心、医养结合机构按床位或人头提供 SaaS 订阅，解决护理人员 "一对多" 用药核对与家属沟通成本。

* **保险与健康管理**：与商业保险、长护险、健康管理机构合作，作为老年用药安全风控与增值服务入口。

* **C 端家属增值（辅）**：家属端高级报告、多长辈管理、药师在线咨询、京东大药房一键复购等增值服务。

* **推广路径**：H5 免安装、扫码即用，便于社区义诊、机构宣教和子女转发，获客与部署成本低。

## 五、技术架构

### 部署平台



* **线上**：腾讯 EdgeOne Pages（静态托管 + Edge Functions 边缘计算）

* **数据存储**：Upstash Redis（REST API，边缘函数直接访问）

* **AI 模型**：火山方舟 doubao-seed-2-0-mini（多模态大模型），承担**药盒识别、AI 用药问答、联合用药分析、防重复话术**四类任务

* **本地开发**：Python `server.py`（ThreadingHTTPServer，端口 8080），镜像线上全部 API

* **离线能力**：Service Worker（PWA），导航网络优先、离线回退缓存，API 请求永不缓存

## 七、已实现功能

### 1. 拍照识药（AI 识别，非演示模式）



* 调用手机后置摄像头（`getUserMedia`），实时取景 + 对准引导；不可用时自动降级为相册选择

* **图片智能压缩**：缩放到 1280px，再逐步降质量（0.8→0.4）和分辨率，确保 base64 ≤ 700KB（边缘函数 1MB 请求体上限）

* **双通道识别**：通道 A 走 POST 直传；通道 B 在 EdgeOne 预览链接丢弃大体积 POST body 时自动切换 GET 分片（每片 5000 字符，经 Redis 临时存储，末片组装识别）

* 多模态模型返回结构化 JSON（药品名、商品名、规格、频次、时间、餐前餐后、禁忌、置信度）

* 识别结果经 "精确 → 包含 → 商品名"**三级匹配内置 50 种药品数据库**，从源头抑制大模型幻觉；未收录药品友好提示、不编造用药信息

### 2. 四问式结果页与语音播报



* 药品名称 + 通俗分类 + 商品名 + 置信度；一天几次 / 什么时间 / 饭前饭后 / 有何禁忌四问大字呈现

* 专业术语自动翻译为大白话（如 "胆碱酯酶抑制剂"→"帮助改善记忆力的药"）

* 识别完成自动 0.8 倍慢速语音播报，重复服药场景优先播报警告，可随时停止

### 3. 防重复服药（本地规则即时拦截 + AI 话术补充）



* 每次确认服药记录到 localStorage（日期、时间、药品 ID），再次识别同种药即时检测

* 命中即显示**红色震动警告**"您今天 X 点已经吃过这个药了"，隐藏 "确认已服用" 按钮并固定语音拦截（**不依赖网络，安全底线**）

* 同时异步请求大模型生成一两句**温和、口语化的个性化提醒话术**（`/api/ask mode=duplicate`），展示于警告卡片并支持 "🔊 再听一遍"；网络或 AI 失败时静默降级，固定警告照常生效

### 4. 药物相互作用：规则 + AI 双通道



* 内置 **40 条**相互作用规则（严重 10 / 警告 22 / 注意 8），双向片段匹配 + 酒精标记，红橙黄三级预警并附老人版解释

* 进入 "历史 / 周报" 页时对所有在用药品即时跑规则速查（毫秒级、离线可用）

* 当在用药品 ≥ 2 种，异步调用大模型 `/api/ask mode=analyze` 输出结构化深度分析（风险等级、一句话结论、最多 5 条要点、总体叮嘱），按药品组合缓存 7 天；AI 失败静默降级为仅规则结果

### 5. AI 用药问答



* 结果页可输入或快捷提问，大模型结合当前药品上下文用大白话作答（≤150 字，涉及剂量 / 换药 / 停药等医疗决策时明确建议咨询医生或药师，末尾固定免责声明）

* 支持语音输入与语音朗读回答

### 6. 家属实时守护



* 患者生成 **8 位绑定码**（120 秒有效），家属输入后双向关联（Redis Set），每人最多关联 10 人，角色校验

* 家属端每 **3 秒**轮询关联患者事件：`medication` 服药通知（进入 30 分钟监视期）、`alert` 紧急求助（弹窗 + 震动 + 系统通知）、`monitor_end` 监视结束、`acknowledge` 家属确认

* 一键拨打患者电话；用药日报含服药统计、漏服检测、冲突总览、时间线，可按日回溯

### 7. 更多适老与照护功能



* AI 用药依从性评分 + 漏服分析 + 个性化建议；异常行为检测（凌晨服药、重复识别预警）

* 药品余量提醒 + 京东大药房一键复购原型；高风险时显示京东健康药师咨询入口

* 用药记录按日分组、今日高亮、酒精摄入标记（参与冲突检测）

### 8. 账号系统与安全



* 手机号 + 密码注册 / 登录，角色选择（患者 / 家人）

* PBKDF2-SHA256 加盐哈希（10000 次迭代）、32 字节随机会话 token（7 天，滑动续期）

* 登录失败 5 次锁定 10 分钟；**密码重置须校验 6 位短信验证码**（5 分钟有效、60 秒重发冷却、每小时上限 5 次、验证码错 5 次作废）

* **8 位绑定码** + 按发起账号的失败锁定（连续错 5 次锁 5 分钟），抵御枚举爆破

* 注册 / 登录 / 重置 / 注销 / 发送验证码等敏感操作一律 **POST**，密码与验证码不进入 URL

* userId 服务端生成、数据按 userId 隔离；僵尸账号自动修复；账号注销校验密码后删除全部数据

### 9. PWA 离线支持



* `manifest.json` 定义名称、图标、主题色与全屏模式，支持 "添加到主屏幕"

* `sw.js` 已启用：**导航请求网络优先**（在线始终加载最新代码并回填缓存）、离线回退缓存的 index.html；静态资源缓存优先 + 网络回填；`/api/*` 纯网络永不缓存，离线时返回结构化错误

## 九、API 接口说明

所有接口部署为 EdgeOne Pages Edge Functions，路径 `/api/*`，响应均带 `Cache-Control: no-store`。

### `/api/auth` — 账号系统



| action     | 方法       | 说明                                                     |
| ---------- | -------- | ------------------------------------------------------ |
| `register` | **POST** | 注册（phone, password, role, displayName），注册即登录           |
| `login`    | **POST** | 登录（phone, password），失败 5 次锁定 10 分钟                     |
| `sendcode` | **POST** | 发送密码重置验证码（phone）；60 秒冷却、每小时 5 次；**验证码经短信下发，不回显**。仅当 `SMS_DEMO_FALLBACK=true` 时才在响应 `demoCode` 返回 |
| `resetpw`  | **POST** | 重置密码（phone, password, **code**），验证码一次性、错 5 次作废         |
| `delete`   | **POST** | 注销账号（phone, password），删除全部数据不可恢复                       |
| `me`       | GET      | 会话验证并滑动续期                                              |
| `logout`   | GET/POST | 登出，销毁当前会话                                              |
| `diag`     | GET      | 账号诊断（仅返回长度 / 存在性，不泄露盐值哈希）                              |

### `/api/ask` — AI 用药助手（POST）



| mode        | 入参                                     | 返回                                                                               |
| ----------- | -------------------------------------- | -------------------------------------------------------------------------------- |
| `qa`（默认）    | `question`（≤200 字）、`drugInfo`          | `{answer, question}`，大白话 ≤150 字并带免责                                              |
| `analyze`   | `drugs`（药名数组，≥2）、`ruleHits`（规则命中摘要，可选） | `{analysis:{level,summary,points[],overallAdvice}}`，失败返回 `{analysis:null}` 供前端降级 |

## 十一、安全边界与原型限制（请在生产部署前阅读）



1. **重置验证码走短信网关**：已接入腾讯云 SMS / 阿里云短信（见下表环境变量），验证码不在 HTTP 响应中返回。未配置短信网关时 `sendcode` 直接返回 503（fail-closed）；如需评审联调，可临时设 `SMS_DEMO_FALLBACK=true` 恢复演示回显，**上线前必须移除该开关**。冷却（60 秒）、频次（每小时 5 次）、有效期（5 分钟）、错 5 次作废等限制均保留；短信发送失败会自动撤销冷却与计数，避免用户空等。

2. **医疗免责**：所有 AI 识别、问答、联合用药分析与话术均为健康科普参考，不构成诊断或处方；涉及剂量调整、换药、停药等必须咨询医生或药师，应用内已固定提示 "以上为 AI 参考，具体请遵医嘱"。

3. **密钥安全**：火山方舟与 Upstash 密钥仅通过边缘函数环境变量 / 本地 `api_config.json` 注入，前端不含任何密钥；请勿把 `api_config.json` 提交到公开仓库。

4. **AI 幻觉控制**：识药结果必须经内置药品库三级匹配，未收录不编造；联合用药分析先跑确定性规则、再让大模型在规则与说明书知识范围内复核，证据不足降级为 "注意 / 咨询药师"。

5. **安全功能不依赖网络**：防重复拦截、规则冲突速查、本地用药记录均在端侧即时执行；AI 能力为增强项，失败一律静默降级。

```
{

&#x20; "api\_endpoint": "https://ark.cn-beijing.volces.com/api/v3/chat/completions",
```

```
\$env:UPSTASH\_REDIS\_REST\_URL="https://your-upstash-url.upstash.io"

```

```
cd 药忆-H5原型

python server.py
```

## 十三、部署到 EdgeOne Pages

在控制台配置环境变量：



| 变量名                        | 说明                                       |
| -------------------------- | ---------------------------------------- |
| `UPSTASH_REDIS_REST_URL`   | Upstash Redis REST URL                   |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash Redis REST Token                 |
| `YAOWI_API_KEY`            | 火山方舟 API Key                             |
| `YAOWI_API_ENDPOINT`       | 火山方舟端点（可选，默认北京区）                         |
| `YAOWI_MODEL_ID`           | 模型 ID（可选，默认 doubao-seed-2-0-mini-260428） |
| `SMS_PROVIDER`             | `tencent`（默认）/ `aliyun`                  |
| `SMS_SECRET_ID`            | 腾讯云 SecretId / 阿里云 AccessKeyId          |
| `SMS_SECRET_KEY`           | 腾讯云 SecretKey / 阿里云 AccessKeySecret     |
| `SMS_SIGN_NAME`            | 已审核通过的短信签名，如"药忆"（不带方括号）             |
| `SMS_TEMPLATE_ID`          | 腾讯云 TemplateId（纯数字）/ 阿里云 TemplateCode（`SMS_` 开头） |
| `SMS_SDK_APP_ID`           | 仅腾讯云：短信应用 SdkAppId                       |
| `SMS_REGION`               | 可选。腾讯云默认 `ap-guangzhou`，阿里云默认 `cn-hangzhou` |
| `SMS_DEMO_FALLBACK`        | 可选。设为 `true` 时未配置短信则回显验证码，**上线必须移除**     |

> 短信模板变量：腾讯云下发 `TemplateParamSet = [验证码, 有效分钟数]`；阿里云下发 `{"code": 验证码, "minutes": 有效分钟数}`。
> 两侧签名实现（Python `_tencent_signature` / JS `tencentSignature`）已用固定时间戳做过一致性验证，见 `test_sms_signature.py`。

部署注意：



* Edge Functions 有 **1MB 请求体上限**，前端已做图片压缩（≤700KB）与 GET 分片兜底

* 预览链接有 **3 小时 token 有效期**，前端已做 token 持久化与过期自动清理

* 账号敏感操作强制 POST，不降级为 GET，避免密码 / 验证码进入 URL 与日志

* 发布新版本后，`sw.js` 的 `CACHE_NAME` 已随版本升级，Service Worker 会自动清理旧缓存；导航请求网络优先，用户在线刷新即获最新版本
